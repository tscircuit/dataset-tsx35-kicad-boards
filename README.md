# dataset-tsx35-kicad-boards

25 KiCad boards from the [Zap comparison](https://zap.mutual.solutions/compare#cmp), reconstructed as native tscircuit TSX: 3,981 PCB components and 4,653 nets. Original PCB placements are retained; silkscreen text and drawings are omitted.

[View on tscircuit.com](https://tscircuit.com/0hmX/dataset-tsx35-kicad-boards)

## Run

```sh
bun install --frozen-lockfile --ignore-scripts
bun run dev
bun run typecheck
bun run build --site
```

`tsconfig.json`, `tscircuit.config.json`, and all six scripts match `tsci init`. Dependencies are pinned for compatibility. A small tracked core dependency patch avoids repeated geometry work in schematic label solvers ([upstream fix](https://github.com/tscircuit/schematic-trace-solver/pull/1331)). To build one board's HTML preview:

```sh
bun run build examples/b03-ftdi-jtag.circuit.tsx --site
```

All 25 boards enable the normal automatic router by default, with `routeRemaining={true}`. Each board uses standard solid GND `<copperpour />` elements on top and bottom with the default 0.2 mm clearance and thermal reliefs. Pours follow the board boundary and flow around routed traces; all layers remain available to the router. Existing ground domains remain separate.

Imported layouts may contain placement findings. Add `--ignore-placement-drc` to run routing without changing their placement.

To build an inspection preview without running the autorouter:

```sh
bun run build examples/b03-ftdi-jtag.circuit.tsx --site --routing-disabled --ignore-placement-drc
```

## Files

- `boards/<id>/`: editable board, footprint, and schematic TSX, plus the upstream license.
- `examples/*.circuit.tsx`: one preview entrypoint per board.
- `upstream-schematics/`: original KiCad schematics and project settings.
- `manifest.json`: entrypoints, counts, and pinned upstream sources; exported by `index.js` with lightweight `index.d.ts` types.

Install the dataset from GitHub with `bun add github:tscircuit/dataset-tsx35-kicad-boards`. No transpilation is needed.

## Scope

All 25 boards matched 15,235 shared physical terminals against KiCad-exported schematic netlists with zero net mismatches. The TSX contains explicit native connections. Generated checking reports and conversion intermediates are excluded from this package.

Original tracks and vias are omitted; running a preview or build generates routes with the normal autorouter. Original KiCad copper-zone shapes are omitted; copper fills are generated by tscircuit. Schematics retain sheet grouping and use native passive symbols or generic boxes. Original component CAD bodies are not included. Full schematic rendering completed for 22 boards; ECP5 DC-SCM, HackRF Pro, and Kintex PCIe exceeded the renderer time limit. Source placement/DRC findings remain; fabrication readiness has not been established.

Each board retains `LICENSE.upstream`. There is no blanket corpus license; `manifest.json` records each original repository, commit, license, and selected PCB.
